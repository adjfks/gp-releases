# 观盘—你的复利日记

本地优先的 A 股复盘桌面应用。记录观察、整理收盘、检验判断，个人复盘保存在自己的电脑里。

[访问官网](https://adjfks.github.io/gp-releases/) · [下载 Windows 当前版](https://github.com/adjfks/gp-releases/releases/latest) · [全部版本](https://github.com/adjfks/gp-releases/releases)

## 当前版本：v0.0.18

- **复盘笔记**：主帖与跟帖支持 Markdown 编辑、预览，跟帖可重新修改；支持搜索、置顶与本机备份。正文识别股票后可请求跳转 Windows 同花顺分时（已验证 PC 9.60.80）。
- **收盘归类**：批量粘贴添加股票，整组按首次/最终涨停时间排序；卡片显示首终时间、炸板次数、公司业务及涨停原因。
- **历史首板晋级 PK**：比较基准日首板股的历史同板晋级情况，保存回测历史与结果。多接口兜底，历史缺口和待核验结果明确展示。
- **日常工作台**：涨停分类、涨停时序、题材梯队、观察池、买卖判断卡、交易复盘、历史龙头库及每日汇总长图。

## 下载与更新

当前仅更新 **Windows x64**，推荐 EXE，另提供 MSI。Mac 暂缓至稳定版，[历史 v0.0.10](https://github.com/adjfks/gp-releases/releases/tag/v0.0.10) 仍可下载，不包含后续新增功能。

Windows 支持应用内检查更新，更新包沿用原私钥签名。当前下载有 5 分钟总时限，慢速网络可能超时；遇到“下载或签名校验失败”，可用浏览器下载 EXE，退出应用后安装升级，无需卸载旧版。安装前请备份个人数据。

`.sig` 和 `latest.json` 用于自动更新，无需手动安装。更新签名与 Windows 代码签名不同，目前安装包未做 Windows 代码签名；Mac 历史包未做 Apple 公证。

本仓库只包含官网、公开安装包和更新文件，不包含桌面源码、个人数据库或备份。公开行情接口有覆盖与时效限制，应用不提供自动交易或收益承诺。

## 官网维护

GitHub Pages 从 `main` 的 `docs/` 部署。纯 HTML / CSS / JavaScript，下载区域读取正式 Release 的 Windows 附件；Mac 历史入口单独保留。接口失败时仍提供下载入口。

官网保留 13 张较早版本的实际组件演示截图，尚未包含新增笔记与回测页面。截图不含个人记录，不代表实时行情。
